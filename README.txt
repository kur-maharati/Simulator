# Electrical Basic Simulator

Aplikasi web pembelajaran rangkaian listrik DC dasar untuk dibuka langsung di browser.

## Menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` menggunakan Chrome, Edge, atau Firefox.
3. Klik komponen di panel kiri untuk menambahkannya.
4. Klik terminal komponen pertama lalu terminal komponen kedua untuk membuat kabel.
5. Pilih komponen untuk mengubah properti, lalu jalankan simulasi.

## Komponen
Baterai, Fuse, Switch, Relay, Rotary Lamp, Dioda, Resistor, LDR, Avometer virtual, Fan, Potensiometer, IC NE555, dan Button.

## Catatan versi
Ini adalah prototipe pembelajaran dengan model koneksi dan status komponen yang disederhanakan. Hasil arus, resistansi, dan kerja NE555/relay belum merupakan analisis rangkaian SPICE atau simulasi fisika komponen yang akurat. Gunakan untuk pengenalan antarmuka, fungsi komponen, dan latihan menyusun koneksi dasar; bukan untuk memvalidasi rangkaian nyata.

## Publikasi
Unggah `index.html`, `style.css`, dan `script.js` ke satu repository GitHub, lalu aktifkan GitHub Pages dari Settings → Pages.
